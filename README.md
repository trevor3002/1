# 🌿 Weed Factory: Green Empire 💰

> A 3D-inspired 2D idle tycoon simulation game designed for mobile (iPhone 13) and desktop browsers. Cultivate exotic strains, automate processing and packaging lines, manage dispensary counter sales, and build a green business empire.

![Screenshot](.playwright-cli/r2-mobile-factory-collected.png)

## 🎮 Gameplay & Features

- **Cultivation Stations**: Plant and harvest 6 distinct fictional strains:
  - *Green Buds* (Tier 1 Starter)
  - *Premium Kush* (Tier 2 Afghan Hybrid)
  - *Purple Haze* (Tier 3 Connoisseur Berry)
  - *Golden Leaf* (Tier 4 High-Potency 24K)
  - *Royal OG* (Tier 5 Boutique Reserve)
  - *Legendary Emerald* (Tier 6 Bioluminescent Mythic)
- **Live Isometric Factory Canvas**: Animated grow lamps, sprouting and flowering colas, bubbling extraction tubes, moving conveyor belts, and customer queues with speech bubbles.
- **Processing & Packaging Lab**: Refines raw harvested buds into cured extracts and packages them into retail jars.
- **Dispensary & Sales Department**: Retail customers queue up to buy available stock. Includes wholesale corporate orders for immediate bulk cash payouts.
- **Market Trends & Fluctuations**: Dynamic events like *"Cannabis Cup Champion: +80% Price Surge!"* with countdown timers.
- **Automation & Staff**: Hire Gary Green-Thumb (auto-planting), Tina Trimmer (auto-harvesting), Dr. Chloe Chemist (auto-processing), Pete Packaging, Ben Budtender (retail sales), and Victoria Vance (VIP wholesale contracts).
- **Empire Rebirth (Prestige)**: Reset your facility in exchange for permanent **Green Tokens** (+5% revenue and +2% speed per token permanently).
- **Offline Earnings**: Timestamp-based offline progression calculations with welcome-back cash collection.
- **Procedural Web Audio**: Built-in sound effects (coins, harvests, cash register, upgrades) and ambient synth lo-fi music without external file dependencies.
- **Mobile-First Responsive Layout**: Optimized for iPhone 13 (390 × 844 CSS viewport) with desktop framing and full-screen display toggle.

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Open in your browser
http://localhost:3000
```

To run the unit tests:
```bash
npm test
```

To build for production:
```bash
npm run build
```

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Audio**: Web Audio API (procedural synthesis)
- **Testing**: Node.js Native Test Runner (`node:test`)
- **Storage**: Browser LocalStorage with manual and auto-save
